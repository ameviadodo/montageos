# Format 03 — Recréer ce contenu viral

1. Mesure la référence : `bin/monteur style "<lien ou mp4>" --name viral-xxx --transcribe`.
2. Regarde les planches (`styles/refs/viral-xxx/…`) et complète `styles/viral-xxx.json` (skill `monteur-copie-style`).
3. Réécris le script sur **ta** structure : même hook, même rythme de révélations, même durée — jamais le même contenu.
4. Tourne, puis `bin/monteur prep RUSH.mp4 --style viral-xxx` → draft → retours frame par frame → master.

**Mesures** : écart de durée ≤ 10 %, coupes/min ± 15 %, même densité de B-roll et de cartes.
